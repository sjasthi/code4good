## 🧭 Part 1 — Why Code for Good?

Discussion points to open the course:
- Recap: students already know Python (from Python DS) — now they'll build **real, usable software**
- The core idea: pick a nonprofit, small business, or community cause and build them a working web app over 30 weeks
- Show 1–2 example outcomes (past capstones, or comparable full-stack student projects) to make the end goal concrete
- Introduce the idea of **incorporation** (LLC or nonprofit) coming in Week 5 — plant the seed early so students start thinking about causes they care about

---

## 🌐 Part 2 — The Web Ecosystem (Big Picture)

Keep this conceptual — no coding yet. Use a simple diagram/analogy (e.g., a restaurant: frontend = dining room, backend = kitchen, database = pantry, deployment = the building itself being open to the public).

Cover at a high level:
- **Frontend** — HTML, CSS, JavaScript (what the user sees and clicks)
- **Backend** — PHP (how the server processes requests)
- **Database** — MySQL (where data is stored)
- **Security** — why login systems and data protection matter
- **DevOps/Deployment** — how a finished app goes live on the internet
- **GenAI tools** — GitHub Copilot (GHCP) as the in-editor coding partner throughout the course, not just at the end

This sets up the "map" students will fill in phase by phase.

---

## 💻 Part 3 — Environment Setup

### 1. GitHub Account
- Create a free GitHub account (use a professional username — this will go on résumés/portfolios)
- Brief explanation: GitHub = where all their code will live and be tracked all 30 weeks

### 2. VS Code
- Download and install VS Code
- Install recommended extensions: GitHub, Live Server, GitHub Copilot

### 3. GitHub Copilot (GHCP) Setup
- Get students set up with the GitHub Copilot extension in VS Code
- **Free tier check:** GHCP's free tier (available with a standard GitHub account, no card required) is our default for this course — since Learn and Help is a nonprofit, we'll rely on free tier access rather than paid seats. Confirm each student can install and activate it under the free tier during class; flag anyone who runs into a signup or eligibility issue so it can be resolved before Week 2
- Explain the ground rule for this course: **GHCP is a pair-programming partner** — used for learning, debugging, and planning, not for skipping understanding
- Quick demo: use Copilot's inline chat/suggestions to explain a simple concept, show how to phrase a good prompt/comment to get useful suggestions
- **Already have Claude Code (paid)?** That's fine to use for your own work — just be ready to translate in-class GHCP demos to your workflow, since instruction will be shown in GHCP

### 4. First Repo
- Each student creates their first GitHub repository (e.g., `code-for-good-[username]`)
- Add a simple `README.md` with their name and one sentence about a cause they might want to support
- Practice one commit + push before class ends

## 📝 Homework (due before Wednesday help session)

1. Confirm GitHub, VS Code, and GitHub Copilot (GHCP, free tier) are all installed and working
2. Push at least one more commit to the new repo (any small change to README is fine)
3. Come with **1–3 candidate ideas** for a nonprofit/business/cause they'd want to build a site for in Week 5

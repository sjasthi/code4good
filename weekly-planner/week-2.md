4. **In-Class Exercise — HTML Prompts to Try**

   **Tier 1 — Structure Basics**
   - "Explain what HTML is and what it's used for, in simple terms."
   - "Create a simple HTML page with a heading, a paragraph, and an image."
   - "Show me the difference between `<div>` and `<span>`, with an example."
   - "What's the difference between block-level and inline elements?"

   **Tier 2 — Common Elements**
   - "Create an HTML page with an ordered list and an unordered list."
   - "Build a simple navigation bar using an unordered list and links."
   - "Show me how to create a table with 3 rows and 3 columns."
   - "What are semantic HTML tags like `<header>`, `<main>`, and `<footer>`, and why should I use them instead of just `<div>`?"

   **Tier 3 — Forms (important for full-stack)**
   - "Create a simple contact form with fields for name, email, and message."
   - "Show me the different `<input>` types (text, email, checkbox, radio, date) with examples."
   - "Explain the difference between GET and POST in an HTML form."
   - "What does the `required` attribute do on a form field?"

   **Tier 4 — Connecting the Dots to Full-Stack**
   - "Create a simple HTML login form and explain what would need to happen on the server when it's submitted."
   - "Show me how to link an external CSS file and a JavaScript file to an HTML page."
   - "Explain what `action` and `method` do on a `<form>` tag."
   - "Create a basic HTML page structure I could use as a template for a full-stack project."

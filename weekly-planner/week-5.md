# 🌟 Code for Good — Week 5

## JavaScript Basics for Python Students

This week, use what you already know in Python to learn JavaScript variables, conditions, loops, and functions. Practice predicting output, running examples, modifying code, and explaining what changed.

5. **In-Class Exercise — From Python to JavaScript**

   Follow **Predict → Run → Modify → Explain** for each task.

   | Task | Practice |
   | --- | --- |
   | Variables | Store an organization name with `const` and a changing donation total with `let`. |
   | Conditions | Write a condition that prints `"Goal reached"` when the total is at least 100. |
   | Arrays & Loops | Store donations in `[10, 20, 30]` and add them using `for...of`. |
   | Functions | Write `totalDonations(amounts)` to return the total. Test both `[10, 20, 30]` and an empty array. |

   **Structured prompt to try with Claude:**

   ```text
   Act as a patient JavaScript tutor.
   Task: Help me write a function that totals an array of donations.
   Context: I know Python lists, loops, and functions, but I am new to JavaScript.
   Format: Explain the Python-to-JavaScript differences, then give one hint at a time.
   Constraints: Use basic JavaScript. Do not give the complete solution until I ask.
   ```

   Run and check any AI-generated code. Be ready to explain how your loop and return statement work.

5. **In-Class Exercise — School Library Campaign**

   | Task | Practice |
   | --- | --- |
   | Select & Update | Change the campaign heading and status message. |
   | Input & Calculate | Read an amount with `.value`, convert it, and display a total. |
   | Style | Toggle a highlight class on the campaign card. |
   | Add & Remove | Create and append a cause; safely remove the first list item. |
   | Explain | Show before/after screenshots and explain two changes. |

   **Suggested 60-minute class flow:** 10 minutes DOM/tree and selectors; 15 minutes content, inputs, and styles; 15 minutes create/remove practice; 10 minutes mission lab; 10 minutes quiz and review.

   **Structured prompt to try with Claude:**

   ```text
   Act as a patient JavaScript tutor.
   Task: Help me update a school library campaign card using the DOM.
   Context: I know Python and basic HTML, CSS, and JavaScript.
   Format: Ask me to predict the result, then give one hint at a time.
   Constraints: Use plain JavaScript, querySelector, textContent, classList,
   createElement, and append. Do not give the full solution until I ask.
   ```

   Run and inspect any AI-generated code. Be ready to explain each DOM operation.

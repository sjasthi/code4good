6. **In-Class Exercise — CSS Prompts to Try**

    Try each prompt as a one-liner first, then rewrite it using the structured template above. Compare the two answers. Paste the CSS Claude gives you into the **CSS Playbook** (or your own `.html` file) and click ▶ Run to see what it does.

    **Tier 1 — CSS Basics**

  - "Explain what CSS is and how it is different from HTML, in simple terms."
  - "Show me the three ways to add CSS to an HTML page (inline, internal, external) with one example of each."
  - "What are the parts of a CSS rule? Label the selector, property, value, and declaration in `h1 { color: orange; }`."
  - "What does the 'Cascading' in Cascading Style Sheets mean? Show a small example where two rules compete."

    **Tier 2 — Selectors, Text and Color**

  - "What is the difference between an element selector, a `.class` selector, and an `#id` selector? Give an example of each."
  - "When should I use a class and when should I use an id?"
  - "Show me how `h1, h2 { ... }` and `.card p { ... }` are different, and what each one selects."
  - "Style a paragraph with a custom font, color, background color, and centered text. Explain each property."

    **Tier 3 — Box Model and Layout**

  - "Explain the box model (content, padding, border, margin) and draw it as a simple text diagram."
  - "What is the difference between `padding` and `margin`? Show an example where changing each one looks different."
  - "What does `box-sizing: border-box` do, and why do most developers add it to every project?"
  - "What is the difference between `display: block`, `inline`, and `inline-block`? Show an example of each."
  - "Build a simple navigation bar with Flexbox. Explain `display: flex`, `justify-content`, and `gap`."

    **Tier 4 — Structured Prompts (use the template!)**

  - Act as a **CSS tutor**. Task: **explain the box model**. Context: **I know HTML but have never written CSS**. Format: **a short explanation followed by one code example with comments**. Constraints: **under 150 words and no jargon**.
  - Act as a **senior front-end developer**. Task: **style my volunteer sign-up page** (paste your HTML). Context: **it is for a local food shelf, and the colors are orange, navy, and white**. Format: **one complete CSS block with comments**. Constraints: **use classes (not ids), `box-sizing: border-box`, and Flexbox for the header**.
  - Act as a **code reviewer**. Task: **review my CSS** (paste your CSS). Context: **I am a beginner and my page looks off**. Format: **a table with Problem | Why it matters | Fix**. Constraints: **under 200 words**.
  - Write your **own** structured prompt that asks Claude to design a one-page website for an organization you care about, then paste the result into a file and open it in your browser.

# Assignment 1: Welcome to Your Coding Environment! 🚀

**Points: 25**

Welcome to your coding class! Before we start writing code, we need to set up our digital toolbox. In this assignment, you will install and configure the essential tools professional developers use every day: **VS Code**, **GitHub**, and **GitHub Copilot (GHCP)**.

---

## 🎯 Objectives
By the end of this assignment, you will:
1. Create a free GitHub account.
2. Install and configure Visual Studio Code (VS Code).
3. Install the GitHub Copilot extension and activate your free access.
4. Verify your setup by writing your very first lines of code with AI assistance.

---

## Step 1: Create a GitHub Account
GitHub is where developers store, share, and collaborate on code. Think of it like Google Drive, but specifically built for software development.

1. Go to [github.com](https://github.com).
2. Click the **Sign up** button in the top right corner.
3. Follow the prompts to enter your email, create a secure password, and choose a username.
4. Complete the verification puzzle and check your email to confirm your account.
5. *(Optional for Students)*: If you are a student, remember to sign up for the **GitHub Student Developer Pack** later to unlock even more free tools and full Copilot access!

---

## Step 2: Install Visual Studio Code (VS Code)
VS Code is our code editor—the workspace where you will type and run your programs.

1. Go to [code.visualstudio.com](https://code.visualstudio.com).
2. Download the installer for your operating system (Windows, macOS, or Linux).
3. Run the installer and follow the on-screen setup instructions. (Tip: Make sure to check the boxes that say "Add to PATH" if prompted on Windows).
4. Open **VS Code** once the installation is complete.

---

## Step 3: Install and Setup GitHub Copilot (GHCP)
GitHub Copilot is your AI pair programmer. It helps you autocomplete code, explains confusing lines, and assists you when you get stuck.

1. Open **VS Code**.
2. On the left-hand sidebar, click on the **Extensions** icon (it looks like four squares, or you can press `Ctrl+Shift+X` on Windows / `Cmd+Shift+X` on Mac).
3. In the search bar at the top, type **GitHub Copilot**.
4. Look for the official extension by **GitHub** and click **Install**.
5. Once installed, a notification will pop up in the bottom-right corner asking you to sign in to your GitHub account. Click **Sign In**.
6. Follow the browser prompt to authorize VS Code to connect with your GitHub account.

---

## Step 4: Test Your Setup!
Let's make sure everything is working correctly.

1. In VS Code, create a new file by clicking **File > New File...** and name it `test.py`.
2. Type the following comment inside your new file and press `Enter`:
   ```python
   # Create a function that greets a user by name
   ```
3. Watch GitHub Copilot suggest the rest of the code in light gray text! Press the `Tab` key to accept the suggestion.
4. Run your code or save your file to confirm your workspace is fully functional.

# Claude 101 & Claude Code 101 — Certifications

**Source:** [Claude Academy — Courses](https://academy.claude.com/courses)

Anthropic's Claude Academy offers free, self-paced courses that end in a quiz and a **completion badge**. Below is an outline of the two entry-level certifications most relevant to our students: **Claude 101** and **Claude Code 101**.

---

## 1. Claude 101

**Link:** [academy.claude.com/courses/claude-101](https://academy.claude.com/courses/claude-101)
**Length:** 13 lessons · 2.5 hr · 1 quiz · Completion badge

### What it's for
Learn to use Claude for everyday work — from your first conversation and effective prompting through Projects, Artifacts, Skills, and connected tools.

### Prerequisites
- A Claude account on any plan (Free, Pro, Max, Team, or Enterprise)
- No prior experience with Claude or other AI assistants needed
- A few features (Cowork, Enterprise Search) need a paid or Team/Enterprise plan to try hands-on — each lesson notes where this applies

### Who it's for
Anyone getting started with Claude at work — first-time users and existing users who want a structured tour of the platform's features.

### What you'll be able to do by the end
- Explain what Claude is and have an effective first conversation with it
- Write clear prompts, refine them when results miss, and apply the AI Fluency framework
- Distinguish the three shapes of work in the desktop app — chat, hand-off, and building software — and know which one a task calls for
- Use Projects, Artifacts, and Skills to organize work and give Claude reusable context
- Connect tools, company knowledge, and the web via Connectors, Enterprise Search, and Research
- Apply Claude across common roles, and get a tour of Claude Code, Claude Tag, Claude Design, Claude for Microsoft 365, and Claude in Chrome

### Course outline
**Meet Claude**
- What is Claude?
- Your first conversation with Claude
- Getting better results
- How you'll work with Claude on your desktop (Chat, Cowork, Code)

**Organizing your work and knowledge**
- Introduction to projects
- Creating with artifacts
- Working with skills

**Expanding Claude's reach**
- Connecting your tools
- Enterprise search
- Research for deep dives

**Putting it all together**
- Claude in action: use-cases by role
- Other ways to work with Claude

**Conclusion & badge**
- What's next?
- Course quiz
- Completion badge

## 2. Claude Code 101

**Link:** [academy.claude.com/courses/claude-code-101](https://academy.claude.com/courses/claude-code-101)
**Length:** 12 lessons · 1.5 hr · 1 quiz · Completion badge

### What it's for
An introduction to Claude Code, Anthropic's agentic coding tool — what it is, how it works, and the core workflows for getting real work done with it.

### Prerequisites (recommended)
- Basic familiarity with a code editor and the command line
- A Claude account (Pro, Max, or Enterprise) or an API key
- No prior experience with AI coding tools assumed

### Who it's for
New developers who want AI-assisted workflows from the start, and experienced engineers who haven't yet tried a coding agent (or tried one and were underwhelmed).

### What you'll be able to do by the end
- Explain what an AI coding agent is and how Claude Code differs from chat-based AI tools
- Understand how the agentic loop, context window, tools, and permissions work together
- Install and set up Claude Code (terminal, VS Code, JetBrains, Claude Desktop, or web)
- Write effective prompts using manual mode, auto-accept, and Plan Mode
- Follow the Explore → Plan → Code → Commit workflow for any feature or task
- Manage context with `/compact`, `/clear`, and `/context`
- Create and maintain a `CLAUDE.md` file for persistent project memory
- Build custom subagents to delegate tasks and keep context clean
- Connect external tools and data sources via MCP servers
- Write hooks for deterministic control over formatting, command blocking, and notifications

### Course outline
**What is Claude Code? (2 lessons)**
- What is Claude Code?
- How Claude Code works

**Your first prompt (2 lessons)**
- Installing Claude Code
- Your first prompt

**Daily workflows (3 lessons)**
- The Explore → Plan → Code → Commit workflow
- Context management
- Code review

**Customizing Claude Code (5 lessons)**
- The CLAUDE.md file
- Subagents
- Skills
- MCP
- Hooks

**Quiz & badge**
- Course quiz
- Completion badge

## Notes for Code for Good / Learn and Help use
- Both courses are free, self-paced, and end with a completion badge students can point to
- Claude 101 has no technical prerequisite — suitable for all students early in the program
- Claude Code 101 assumes basic editor/command-line familiarity and a Pro/Max/Enterprise account or API key — best introduced once students are comfortable with GitHub/VS Code setup (Week 1) and have started writing code
- Since this course currently standardizes on GitHub Copilot (GHCP) as the primary in-editor AI tool, Claude Code 101 is best framed as an optional/enrichment certification for students who want to explore agentic coding further, rather than a required course-wide milestone
